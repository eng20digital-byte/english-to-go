# B3.2 — Back cover instant (reduced-motion baseline)

> Second sub-milestone of [B3](./B3-reader-back-cover.md). Builds on
> [B3.1](./B3.1-split-back-cover-from-spreads.md).

## Goal
Wire the back cover state machine and navigation so the back cover appears and
disappears **instantly** (no animation). This is the `prefers-reduced-motion`
baseline and the simplest possible working back cover — the same path C3.2 took
for the front cover. Animations are layered on in B3.3/B3.4.

## Scope

### `src/reader/BookBackCover.tsx` — new file

A minimal component that renders the back cover **portrait canvas** centered in
the same flex box as the open book. At this stage: no animation CSS classes,
no leaf, no card framing transition — just the correctly-sized `PageCanvas`.

```typescript
type BackCoverState = 'hidden' | 'entering' | 'exiting' | 'visible';

interface BookBackCoverProps {
  backCover: ReaderBookletPage;
  lastSpread: ReaderBookletPage;
  spreadCount: number;
  backCoverState: BackCoverState;
  onClose: () => void;      // tap / swipe-right → exit to last spread
  onEnterEnd: () => void;   // enter animation finished → 'visible'
  onExitEnd: () => void;    // exit animation finished → 'hidden'
}
```

For this milestone: render a centred portrait card (same outer box as
`BookCover`'s outer box and as the open-book wrapper — `flex:1; maxWidth:
min(1920px, calc((100vh - 40px) * (1920/1080)))`) containing a clipped-to-left-
half full-spread card:

```
outer box (flex:1, same maxWidth as open book)
└─ card (width:100%, aspectRatio:1920/1080, overflow:hidden)
   clipPath: 'inset(0 50% 0 0)'
   transform: 'translateX(25%)'
   └─ PageCanvas (back cover page, scale from useCanvasScale on card)
```

The static closed framing is the held first frame of the enter animation (defined
in B3.3 as `back-cover-card-enter`). Setting it inline here means B3.3 just
attaches the CSS class — no layout rewrite.

**Tap / swipe-right to exit**: same pointer handling as `BookCover`'s swipe-to-
open, but mirrored — a **rightward** swipe past the threshold calls `onClose`;
a leftward swipe (there's nothing after the back cover) is ignored:
```typescript
if (deltaX < -threshold) return;   // leftward — ignore
onClose();                          // rightward or tap → close
```

At this milestone: `onEnterEnd` and `onExitEnd` are called immediately on mount
(since there's no animation yet). The parent state machine drives visibility.

Scale: `useCanvasScale(cardRef, CANVAS_WIDTH)` — the card is always the full
spread; the cover face (half the card) shares this scale exactly as `BookCover`
does.

### `src/reader/ReaderBookletPage.tsx`

**Handlers:**
```typescript
const enterBackCover = useCallback(() => {
  // B3.3 will add the animated path here (prefersReducedMotion check).
  // For now always jump straight to 'visible'.
  setBackCoverState('visible');
}, []);
const finishEntering  = useCallback(() => setBackCoverState('visible'), []);

const exitBackCover = useCallback(() => {
  // B3.4 will add the animated path here.
  setBackCoverState('hidden');
}, []);
const finishExiting = useCallback(() => setBackCoverState('hidden'), []);

const showBackCover = backCoverState !== 'hidden';
```

**Navigation:**
- `nextDisabled`: at last spread, enable "next" when `backCover` exists and the
  back cover isn't already showing:
  ```typescript
  const nextDisabled = isFlipping
    || (showCover)
    || (showBackCover)
    || (clampedIndex === spreads.length - 1 && !backCover);
  ```
- `handleNext()`: if `clampedIndex === spreads.length - 1 && backCover && !showBackCover`
  → `enterBackCover()`; otherwise delegate to `flipControlsRef.current?.next()`.
- `handlePrev()`: if `showBackCover` → `exitBackCover()`; otherwise the existing
  `canClose` check and `flipControlsRef.current?.prev()`.

**Keyboard effects** — two new `useEffect`s mirroring the cover open/close
effects:
- While `showBackCover && !isFlipping`: `ArrowLeft` → `exitBackCover()`.
- While `clampedIndex === spreads.length - 1 && backCover && !showBackCover && !showCover`:
  `ArrowRight` → `enterBackCover()`. (PageFlip's own ArrowRight no-ops at the
  last index, so no conflict.)

**Rendering** — add the back cover branch alongside the existing cover branch:
```tsx
{showBackCover && backCover ? (
  <BookBackCover
    backCover={backCover}
    lastSpread={spreads[spreads.length - 1]}
    spreadCount={spreads.length}
    backCoverState={backCoverState}
    onClose={exitBackCover}
    onEnterEnd={finishEntering}
    onExitEnd={finishExiting}
  />
) : (
  /* existing: showCover ? <BookCover …> : <open-book subtree> */
)}
```

The `VocabularyPanel` line: extend `!showCover` to also hide it while back cover
is visible (`!showCover && !showBackCover`).

## Manual verification
1. At the last spread, click **next** / ArrowRight → the back cover portrait
   appears **instantly**; PageFlip, the page indicator, and the sheet edges
   unmount; only the centered portrait page is shown.
2. Click **prev** / ArrowLeft / swipe-right → returns to the last spread
   instantly; PageFlip remounts at the last index.
3. Tap the back cover → exits instantly to the last spread (same as swipe-right).
4. The **next** button is disabled on the back cover (nothing after it).
5. The **prev** button is disabled on the back cover's… wait, no — prev exits to
   the last spread. Confirm it is enabled and functional.
6. `prefers-reduced-motion: reduce` — same instant behaviour (this is the
   baseline; no animation to skip).
7. **No back cover**: a booklet without one behaves exactly as before — next is
   disabled at last spread (regression check).
8. **Front cover + back cover** co-exist: opening from the front cover works as
   before; reaching the back cover from the last spread works; prev from back
   cover returns to last spread; prev at spread 0 still re-closes the front cover.
9. `npm run lint` + typecheck clean.
