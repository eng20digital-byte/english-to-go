# B3.3 — Enter animation (last spread → back cover)

> Third sub-milestone of [B3](./B3-reader-back-cover.md). Builds on
> [B3.2](./B3.2-back-cover-instant.md) (instant baseline).

## Goal
Replace the instant enter with a **sequential two-phase animation** that mirrors
the front cover's open animation in reverse:

1. **Flip** — the left-half leaf rotates from its hidden position (`180°`) to
   flat (`0°`), revealing the back cover face. The last spread's **right** page
   rides the leaf's back face, disappearing as the leaf passes 90°.
2. **Reframe (collapse)** — once the flip lands, the full-spread card collapses
   leftward to the centered portrait framing (`clip-path: inset(0 50% 0 0)` +
   `translateX(25%)`).

This is the exact reverse of the front cover's sequential open (C4.2: reframe →
flip). Here it is flip → reframe.

**Right page comes only from the flipping leaf, never the base.** The base layer
(last spread, rendered under the leaf) is clipped to its **left half** while
`'entering'` — otherwise the collapse would reveal the base's right page
alongside the flipping leaf. With the base clipped, the right page is delivered
solely by the leaf's back face as it rotates, and the frame is seam-free at the
`'visible'` settle. The clip is entering-only: the live open book (B3.2) and the
exit animation (B3.4) keep the full base.

Reduced motion keeps the B3.2 instant path.

## How

Two existing animation tools are reused:
- **Leaf flip**: a new `.back-cover-leaf--entering` class with keyframes
  `rotateY(180deg) → rotateY(0deg)` for `PAGE_FLIP_DURATION_MS`.
- **Card reframe (collapse)**: a new `.back-cover-card--entering` class with
  keyframes `clip-path: inset(0 0 0 0) → inset(0 50% 0 0)` and
  `translateX(0) → translateX(25%)`, delayed by `PAGE_FLIP_DURATION_MS`.

Same sequencing trick as C4.2 (open: reframe first, then flip with a delay) —
here the order is inverted (flip first, then reframe with a delay). Both driven
by inline CSS vars.

## Exact changes

### `src/index.css` — back cover enter CSS

```css
/* Back cover leaf: left half of spread, pivot at spine (right edge) */
.back-cover-leaf {
  position: absolute;
  top: 0;
  left: 0;                     /* left half — mirror of .page-flip-sheet's left:50% */
  width: 50%;
  height: 100%;
  z-index: 2;
  transform-origin: right center; /* spine is on the right — mirror of left center */
  transform-style: preserve-3d;
  animation-fill-mode: forwards;
}

/* Enter: back face (last spread right) → front face (back cover design) */
.back-cover-leaf--entering {
  animation-name: back-cover-leaf-enter;
}
@keyframes back-cover-leaf-enter {
  from { transform: rotateY(180deg); }
  to   { transform: rotateY(0deg); }
}

/* Card collapse: full spread → left-half portrait (delayed by flip duration) */
.back-cover-card--entering {
  animation: back-cover-card-enter var(--reframe-dur, 650ms) var(--easing, ease)
             var(--flip-dur, 1000ms) forwards;
                                /* ↑ delay = flip duration so collapse starts after flip */
}
@keyframes back-cover-card-enter {
  from { clip-path: inset(0 0 0 0);   transform: translateX(0); }
  to   { clip-path: inset(0 50% 0 0); transform: translateX(25%); }
}

/* Fore-edge stack (left side) tracking during enter */
.back-cover-edge--entering {
  animation-name: back-cover-edge-enter;
  animation-fill-mode: forwards;
}
@keyframes back-cover-edge-enter {
  /* Stack starts at left:0 (the open book's left edge), ends at right:75%
     (the closed back cover's left edge). Uses `right` property like the
     front cover edge animation uses `left`. */
  from { right: 0%; }
  to   { right: 75%; }
}

/* Shade gradient for back cover leaf:
   spine is on the RIGHT, so darken toward the right (mirror of .page-flip-shade) */
.back-cover-shade {
  /* same structure as .page-flip-shade but gradient direction reversed */
  background: linear-gradient(
    to left,
    rgba(0, 0, 0, 0.5) 0%,
    rgba(0, 0, 0, 0.06) 55%,
    rgba(0, 0, 0, 0) 100%
  );
  /* opacity ramp and all other rules are the same — reuse .page-flip-shade
     for those; only override gradient direction here */
}
.back-cover-shade--back {
  background: linear-gradient(
    to right,
    rgba(0, 0, 0, 0.5) 0%,
    rgba(0, 0, 0, 0.06) 55%,
    rgba(0, 0, 0, 0) 100%
  );
}
```

**HARD RULE (same as `.page-flip-sheet`):** never put `overflow` / `clip-path` /
`opacity` / `filter` on `.back-cover-leaf` — they would silently collapse
`transform-style: preserve-3d`. Clip/translate live on the **card** only; shading
lives on flat face children.

### `src/reader/BookBackCover.tsx` — full enter animation

Add the leaf and base layer. Full card structure for the `'entering'` state:

```
outer box (flex:1, maxWidth — same as open-book wrapper)
├─ left fore-edge stack   .back-cover-edge .back-cover-edge--entering  (absolute, right: 0%)
└─ card (width:100%, aspectRatio:1920/1080, overflow:hidden, perspective)
   class: back-cover-card--entering   (CSS vars: --flip-dur, --reframe-dur, --easing)
   ├─ base (position:absolute, inset:0)
   │   clipPath: 'inset(0 50% 0 0)'   ← clipped to LEFT half while entering
   │   └─ PageCanvas(lastSpread, scale, renderMode:'reader')
   ├─ .book-spine  (shown during animation)
   └─ .back-cover-leaf .back-cover-leaf--entering
      animationDuration: PAGE_FLIP_DURATION_MS
      animationTimingFunction: PAGE_FLIP_EASING
      onAnimationEnd: filter to 'back-cover-leaf-enter' → call onEnterEnd
      ├─ .page-flip-face .page-flip-face--front
      │   └─ PageCanvas(backCover, scale, canvasWidth:COVER_CANVAS_WIDTH,
      │                 canvasHeight:COVER_CANVAS_HEIGHT, renderMode:'reader')
      │   └─ .back-cover-shade  (shade animation: same timing as leaf)
      └─ .page-flip-face .page-flip-face--back   (pre-rotated 180deg — inherited)
          └─ 200% wrapper anchored right:0, clipPath:'inset(0 0 0 50%)'
             └─ PageCanvas(lastSpread, scale, renderMode:'reader')
          └─ .back-cover-shade .back-cover-shade--back
```

The **back face** of the back cover leaf mirrors the front cover's back face but
for the **right** half:
- Front cover back face: 200% wrapper `left:0`, `clipPath: inset(0 50% 0 0)` →
  shows left half of spread 0.
- Back cover back face: 200% wrapper `right:0`, `clipPath: inset(0 0 0 50%)` →
  shows right half of last spread.

The `onEnterEnd` callback fires on the **leaf's** `animationend` (filtered to
`back-cover-leaf-enter`). The card reframe animation finishes later (after the
delay), but the leaf's end is the user-facing moment when the face swap
completes; the reframe is a sub-second collapse that follows. After `onEnterEnd`:
`backCoverState = 'visible'` → the static closed framing from B3.2 takes over
(inline `clipPath`/`transform`), seamlessly matching where the card animation
lands.

## Manual verification
1. At the last spread, trigger "next" → the **back cover leaf flips in** from the
   left-side hidden position (`180° → 0°`), the last spread's **right page rides
   the leaf's back face** and disappears past 90° — it does **not** appear flat on
   the base during the flip. Only after the leaf settles does the card **collapse
   leftward** to the centered portrait.
2. **Base is clipped during flip** — confirm the last spread's right half is
   delivered only by the back face, not the base layer.
3. **Fore-edge stack** tracks the collapse: sits at the card's left edge, sweeping
   from position 0% to the settled portrait position.
4. **Handoff** — at `'visible'` settle, the portrait position matches exactly
   (same `clip-path`/`transform` values), no jump or seam.
5. **Reduced motion** — still an instant jump to `'visible'`.
6. **Exit still works** (B3.2's instant exit is unchanged — that gets animated in
   B3.4).
7. **Front cover open animation** — completely unaffected (regression check).
8. `npm run lint` + typecheck clean.
