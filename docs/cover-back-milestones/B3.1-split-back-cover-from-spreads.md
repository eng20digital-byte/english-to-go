# B3.1 — Split back cover from spreads

> First sub-milestone of [B3](./B3-reader-back-cover.md). Data plumbing only —
> no visible change yet.

## Goal
Isolate the back cover page from `spreads` in `ReaderBookletPage` and introduce
the `BackCoverState` type, so subsequent sub-milestones have a clean state
machine to build on. The reader still opens to spread 0 and works exactly as
today.

## Scope

### `src/reader/ReaderBookletPage.tsx`

**Replace the current spreads derivation:**
```typescript
// Before (front-cover-only):
const cover   = booklet.pages.find((p) => p.is_cover) ?? null;
const spreads = cover ? booklet.pages.slice(1) : booklet.pages;

// After (front + back cover aware):
const cover     = booklet.pages.find((p) => p.is_cover)      ?? null;
const backCover = booklet.pages.find((p) => p.is_back_cover) ?? null;
const spreads   = booklet.pages.filter((p) => !p.is_cover && !p.is_back_cover);
```

The `filter` replaces the `slice(1)` — it safely handles booklets that have only
a back cover (no front cover), only a front cover (existing behaviour), both, or
neither.

**Add the `BackCoverState` type and initial state** (no handlers yet — that is
B3.2):
```typescript
type BackCoverState = 'hidden' | 'entering' | 'exiting' | 'visible';
const [backCoverState, setBackCoverState] = useState<BackCoverState>('hidden');
```

Also reset `backCoverState` to `'hidden'` in the existing "adjust state on
booklet change" block (mirrors the `setCoverState('closed')` reset there).

No rendering changes yet — `showBackCover` is always false, the back cover
branch is dead code at this point.

### No other files change in this sub-milestone.

## Manual verification
1. Booklets with a **front cover only** — behaviour completely unchanged.
2. Booklets with a **back cover** — the reader opens to spread 0, paging works,
   the back cover page is **not counted** in the dot indicator or page counter.
3. Booklets with **both covers** — same: opens to spread 0, indicator counts
   spreads only (neither cover counted).
4. Booklet with only a back cover (edge case): spreads array is empty → hits the
   existing "no pages" error state gracefully.
5. `npm run lint` + typecheck clean.
