# B3.4 — Exit animation (back cover → last spread)

> Fourth and final sub-milestone of [B3](./B3-reader-back-cover.md). Builds on
> [B3.3](./B3.3-enter-animation.md) (enter animation).

## Goal
Animate the return from back cover to the last spread — the exact reverse of B3.3:

1. **Reframe (expand)** — the centered portrait card expands rightward back to
   the full spread.
2. **Flip** — once the card lands in the full-spread slot, the back cover leaf
   rotates from flat (`0°`) back to its hidden position (`180°`), revealing the
   last spread's right page sweeping in from the leaf's back face. On the leaf's
   `animationend` → `onExitEnd` → `'hidden'` → `PageFlip` remounts at the last
   index.

This is the exact reverse of the enter (B3.3: flip → reframe). Here it is
reframe → flip. Mirrors C4.3 (front cover re-close: flip → collapse) but for
the back cover direction.

**Right page comes only from the flipping leaf, never the base.** While
`'exiting'` the base (last spread) is clipped to its **left half** — the same
clip used during `'entering'`. The right page is delivered by the leaf's back
face as it sweeps past 90°, landing the frame identically to what `PageFlip`
then renders at spread `n-1`. Remove the base clip once `'hidden'`.

Reduced motion keeps the B3.2 instant path (unchanged).

## How

Same sequencing logic as B3.3 but reversed:

- **Card expand**: `.back-cover-card--exiting` — the reverse of
  `back-cover-card-enter` — runs first with delay `0`.
- **Leaf flip**: `.back-cover-leaf--exiting` — `rotateY(0deg) → rotateY(180deg)`
  — delayed by `COVER_REFRAME_DURATION_MS` so it starts after the card expand.
- On the **leaf's** `animationend` (filtered to `back-cover-leaf-exit`) →
  `onExitEnd()` → `backCoverState = 'hidden'` → `PageFlip` remounts.

## Exact changes

### `src/index.css` — back cover exit CSS

```css
/* Leaf exit: front face (back cover design) → back face (last spread right) */
.back-cover-leaf--exiting {
  animation-name: back-cover-leaf-exit;
}
@keyframes back-cover-leaf-exit {
  from { transform: rotateY(0deg); }
  to   { transform: rotateY(180deg); }
}

/* Card expand: left-half portrait → full spread (runs first, delay:0) */
.back-cover-card--exiting {
  animation: back-cover-card-exit var(--reframe-dur, 650ms) var(--easing, ease) forwards;
}
@keyframes back-cover-card-exit {
  from { clip-path: inset(0 50% 0 0); transform: translateX(25%); }
  to   { clip-path: inset(0 0 0 0);   transform: translateX(0); }
}

/* Fore-edge stack tracking during exit (mirrors enter, reversed) */
.back-cover-edge--exiting {
  animation-name: back-cover-edge-exit;
  animation-fill-mode: forwards;
}
@keyframes back-cover-edge-exit {
  from { right: 75%; }
  to   { right: 0%; }
}
```

### `src/reader/BookBackCover.tsx` — full exit animation

The `'exiting'` state uses the same tree as `'entering'` (same one-tree principle
as `BookCover` — `closed`/`opening`/`closing` differ only by class names and a
couple of inline toggles; no remount). The `exiting` classes replace `entering`
classes; the base clip and leaf back face are unchanged.

```typescript
const cardClass = isEntering
  ? 'back-cover-card--entering'
  : isExiting
    ? 'back-cover-card--exiting'
    : '';
const leafClass = isEntering
  ? 'back-cover-leaf--entering'
  : isExiting
    ? 'back-cover-leaf--exiting'
    : '';
const edgeClass = isEntering
  ? 'back-cover-edge--entering'
  : isExiting
    ? 'back-cover-edge--exiting'
    : '';
const leafAnimName = isEntering ? 'back-cover-leaf-enter' : 'back-cover-leaf-exit';
const onLeafEnd    = isEntering ? onEnterEnd : onExitEnd;
```

Leaf inline timing — exiting: same `PAGE_FLIP_DURATION_MS` + `PAGE_FLIP_EASING`
but with **`animationDelay: COVER_REFRAME_DURATION_MS`** so it starts after the
card expand (reversed order from entering, where the card had the delay):

```typescript
const leafStyle = {
  animationDuration:        `${PAGE_FLIP_DURATION_MS}ms`,
  animationTimingFunction:  PAGE_FLIP_EASING,
  animationDelay:           isExiting ? `${COVER_REFRAME_DURATION_MS}ms` : undefined,
};
```

(On enter the card had the delay; on exit the leaf has the delay — the two
phases swap roles.)

Card inline vars (both entering and exiting need `--reframe-dur`, `--easing`,
and for entering `--flip-dur`):
```typescript
const cardVars = {
  '--reframe-dur': `${COVER_REFRAME_DURATION_MS}ms`,
  '--flip-dur':    `${PAGE_FLIP_DURATION_MS}ms`,
  '--easing':      PAGE_FLIP_EASING,
} as CSSProperties;
```

`onAnimationEnd` on the leaf: filter to `leafAnimName` → call `onLeafEnd`. The
card's `animationend` bubbles up from `.back-cover-card` (a child) and must be
filtered out — the leaf's own event is the correct signal, as the leaf finishes
last on exit (reframe → then leaf flip).

### `src/reader/ReaderBookletPage.tsx`

Update `exitBackCover`:
```typescript
const exitBackCover = useCallback(() => {
  setBackCoverState(prefersReducedMotion() ? 'hidden' : 'exiting');
}, []);
```

(The `finishExiting` callback sets state to `'hidden'` — unchanged from B3.2.)

On `'hidden'`: `PageFlip` remounts. It initialises at `currentIndex =
clampedIndex = spreads.length - 1` (the last spread) — no explicit index reset
needed, the state is already there.

## Manual verification
1. On the back cover (portrait, static), trigger **prev** / ArrowLeft / swipe-right
   → the card **expands rightward** to the full spread first (back cover portrait
   becomes the left page); only after the card lands does the **back cover leaf
   flip back** (`0° → 180°`), the last spread's right page sweeping in from the
   leaf's back face.
2. **Base clip during exit** — confirm the last spread's right half is delivered
   only by the leaf's back face during the flip phase; not the base.
3. **Handoff** — on `animationend` `PageFlip` remounts at the last spread index;
   no seam or scale jump between the leaf's landing position and `PageFlip`'s
   spread 0 right page.
4. **Exit fore-edge stack** tracks the card's expanding left edge back to `right:
   0%`.
5. **Static spine** — while the back cover is in the `'visible'` state (not
   animating), the right-side spine shadow is visible at the cover's right edge.
6. **Reduced motion** — instant exit still lands in `'hidden'` with `PageFlip`
   remounted at last spread.
7. **Enter → exit → enter** cycle works cleanly: no leaked animation state, no
   duplicate callbacks.
8. **Front cover open/close** — completely unaffected (regression check).
9. **Quiz page as last spread** — exit from back cover remounts `PageFlip` at the
   quiz spread; the quiz embed re-renders correctly.
