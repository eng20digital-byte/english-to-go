# C3.2 — Reader: closed cover stage + instant open (no animation)

> Second of the four-part split of [C3](./C3-reader-closed-cover.md). Builds on
> [C3.1](./C3.1-split-cover-from-spreads.md).

## Goal
Introduce `coverState` and a new `BookCover` that renders the centered
single-page **closed** cover with closed-book chrome (right fore-edge stack, left
spine shadow). While not open, render `BookCover` instead of the open book.
Opening via **click/tap cover, next button, ArrowRight, Enter, swipe-left**
switches **instantly** to the open book at spread 0. Prev disabled, vocab panel +
indicator + open-book edges hidden while closed.

The instant open/close here doubles as the eventual `prefers-reduced-motion` path
— C3.3 / C3.4 only layer animation on top of this fully-working baseline.

## Files
- **New** `src/reader/BookCover.tsx`
- Modify [ReaderBookletPage.tsx](../../src/reader/ReaderBookletPage.tsx)
- Modify [index.css](../../src/index.css) — add a `.book-cover-spine` left-edge
  binding shadow; reuse `.book-edge--right` for the fore-edge stack.

## Exact changes

### ReaderBookletPage
- State:
  ```ts
  type CoverState = 'closed' | 'opening' | 'closing' | 'open';
  const [coverState, setCoverState] = useState<CoverState>('closed');
  ```
- `const hasCover = cover !== null;` and
  `const showCover = hasCover && coverState !== 'open';` (no-cover ⇒ `showCover`
  always false ⇒ no flash, no init effect needed). Reset to `'closed'` in an
  effect keyed on `booklet?.id`.
- `const openCover = useCallback(() => setCoverState('open'), []);` (instant for
  now).
- Route the arrow buttons through reader handlers:
  ```ts
  const handleNext = () => { if (showCover) return openCover(); flipControlsRef.current?.next(); };
  ```
  - next button `onClick={handleNext}`
  - `nextDisabled = isFlipping || (!showCover && clampedIndex === spreads.length - 1)`
  - `prevDisabled = isFlipping || showCover || clampedIndex === 0`
- Window keydown effect gated on `showCover`: `ArrowRight` / `Enter` →
  `openCover()` (PageFlip isn't mounted while closed, so no conflict).
- In the flex row's middle slot, swap:
  `showCover ? <BookCover …/> : <div book wrapper>…PageFlip…</div>`. Hide
  `<VocabularyPanel/>` while `showCover` (indicator + open-book `.book-edge`
  stacks disappear automatically because the whole PageFlip subtree is unmounted).

### BookCover (closed render)
- Props: `{ cover: ReaderBookletPage; onOpen: () => void }`.
- Centered sizing wrapper, height-bound to portrait
  `aspectRatio: COVER_CANVAS_WIDTH / COVER_CANVAS_HEIGHT`; card with
  `overflow:hidden`, rounded, same `boxShadow` as the booklet card.
- Inside: `useCanvasScale(coverRef, COVER_CANVAS_WIDTH)` →
  ```tsx
  <PageCanvas
    page={cover}
    scale={scale}
    renderMode="reader"
    canvasWidth={COVER_CANVAS_WIDTH}
    canvasHeight={COVER_CANVAS_HEIGHT}
  />
  ```
- Closed chrome: `.book-edge.book-edge--right` translated `translateX(100%)` just
  outside the right edge, width `spreads.length × BOOK_SHEET_THICKNESS_PX`; a
  `.book-cover-spine` gradient on the left (binding) edge.
- Own pointer handlers: click/tap → `onOpen()`; swipe-left past
  `SWIPE_THRESHOLD_*` → `onOpen()`.

## Manual verification
1. **Cover booklet** opens closed: centered portrait cover, right fore-edge stack,
   left spine shadow, no spread, no indicator, prev disabled, vocab hidden.
2. Click cover / next / ArrowRight / Enter / swipe-left → instantly shows open
   spread 0; thereafter flip / dots / counter (spreads only) / vocab / edges
   behave exactly as C3.1.
3. **Seamless handoff**: the closed portrait card and the open-book card occupy
   the same on-screen box (cover = exactly half a spread).
4. **No-cover booklet**: opens straight to spread 0, unchanged.
5. `prefers-reduced-motion`: identical (already instant). `npm run lint` +
   typecheck clean.
