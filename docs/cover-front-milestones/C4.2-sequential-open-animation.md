# C4.2 — Sequential open animation (slide → flip)

> Second of the [C4](./C4-cover-open-rework.md) fix set. Builds on
> [C4.1](./C4.1-unify-cover-geometry.md) (unified geometry / single tree).

## Goal

Replace the combined "slide + flip at once" open with the intended **sequential**
motion:

1. **Reframe (slide)** — the centered half-page cover slides into the open book's
   **right-hand page slot**. The cover stays flat (no rotation) during this
   phase, and the left side opens to **only the reader background** — spread 0's
   left page is deliberately *not* revealed yet (see below).
2. **Flip** — once it lands, the cover does the normal page-turn (leaf
   `0°→-180°`), revealing spread 0. The left page appears **gradually, from the
   back side of the cover** (the leaf's back face) as the leaf passes 90°, like a
   real book opening — never popping in flat during the slide. On the leaf's
   `animationend` → `onOpenEnd` → `'open'`, handing off to `PageFlip` at spread 0.

**Left page comes only from the flipping leaf, never the base.** The base layer
(spread 0, rendered under the leaf) is clipped to its **right half while
`opening`** — otherwise the slide's clip-path un-clip would reveal the base's
left page flat on the left before the cover ever flipped. With the base clipped,
the left page is delivered solely by the leaf's back face rotating over it, and
the frame is seam-free at the `'open'` handoff (leaf back face = spread 0 left
page at the same geometry PageFlip then renders). The clip is opening-only: close
(collapse) and the live book keep the full base.

Reduced motion stays instant (unchanged).

## How

The reframe is already exactly `@keyframes book-cover-expand`
(`clip-path: inset(0 0 0 50%) → inset(0 0 0 0)` + `translateX(-25%) → 0`). The flip
is already the leaf's `page-turn-next`. We only need to run them **one after the
other** instead of together — done with an **animation delay** on the leaf equal to
the reframe duration. No new React sub-state; the `'opening'` stage stays a single
parent state, the sequencing lives in CSS + inline vars.

## Exact changes

### config/reader.ts

Add (no magic numbers in components):

```ts
// Cover open/close phase 1: the centered cover sliding into the open book's
// right-hand page slot (clip-path un-clip + translateX), before the cover leaf
// flips. The leaf flip (PAGE_FLIP_DURATION_MS) is delayed by this amount on open,
// and the card collapse is delayed by the flip duration on close (see C4.2/C4.3).
export const COVER_REFRAME_DURATION_MS = 650;
```

### index.css

`book-cover-expand` keyframes are unchanged (still the reframe). Only the timing
moves to config-driven vars:

- `.book-cover-card--opening` runs `book-cover-expand` for the **reframe** duration
  (var, e.g. `--reframe-dur`), delay `0`.
- The leaf (`.page-flip-sheet--next`) and its shades run `page-turn-next` /
  `page-flip-shade` for `PAGE_FLIP_DURATION_MS` with **`animation-delay:
  var(--reframe-dur)`** so the flip starts after the reframe. During the delay the
  leaf rests at `rotateY(0)` (its non-animated state = flat = cover as the right
  page), which is correct — no `animation-fill-mode: backwards` needed.

Drive both via inline CSS vars from BookCover so the durations stay in config.

### BookCover — opening branch

- Card inline style (opening): `'--reframe-dur': '${COVER_REFRAME_DURATION_MS}ms'`,
  `'--easing': PAGE_FLIP_EASING` (and keep `--dur` if other rules read it).
- Leaf + both shades (opening): `animationDuration: '${PAGE_FLIP_DURATION_MS}ms'`,
  `animationTimingFunction: PAGE_FLIP_EASING`, **`animationDelay:
  '${COVER_REFRAME_DURATION_MS}ms'`**.
- **Callback unchanged for open**: `onOpenEnd` still fires on the **leaf's**
  `animationend`, filtered to `event.animationName === 'page-turn-next'` — the leaf
  is still the last thing to finish on open (reframe → then flip). Total open time
  ≈ `COVER_REFRAME_DURATION_MS + PAGE_FLIP_DURATION_MS`.

> HARD RULE (unchanged, see `.page-flip-sheet`): clip-path / transform / opacity /
> filter live on the **card** only, never the leaf — the only new thing on the leaf
> is `animation-delay`.

## Manual verification

1. **Open is two-phase** — trigger open (click / tap / ArrowRight / Enter): the
   centered cover **slides right** into the right page slot with the left side
   showing **only the background** (no left page yet), and **only after it lands**
   does the cover flip open — the left page sweeping in **from the back of the
   cover** as it passes edge-on. The two motions are clearly sequential, not
   simultaneous, and the left page is never visible before the flip reveals it.
2. **Spine + handoff** — spine settles centered; no jump at the start (centered →
   slot) and **no seam** at the end (BookCover → PageFlip at spread 0).
3. **Back face** — past 90° the leaf shows spread 0's left page.
4. **Reduced motion** — still an instant jump to `'open'`.
5. **No-cover booklet / normal spread flips** — unchanged. `npm run lint` +
   `npm run build` clean.
