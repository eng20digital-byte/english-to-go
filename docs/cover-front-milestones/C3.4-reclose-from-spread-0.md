# C3.4 — Reader: re-close from spread 0

> Last of the four-part split of [C3](./C3-reader-closed-cover.md). Builds on
> [C3.3](./C3.3-open-animation.md).

## Goal
`prev` while open **at spread 0** (cover present) re-closes: `'closing'` plays the
reverse animation → `'closed'`. Inputs: prev button, ArrowLeft, swipe-right.
Reduced motion → instant jump to `'closed'`.

## Files
- Modify [ReaderBookletPage.tsx](../../src/reader/ReaderBookletPage.tsx)
- Modify `src/reader/BookCover.tsx`
- Modify [index.css](../../src/index.css)

## Exact changes

### ReaderBookletPage
- `const canClose = hasCover && coverState === 'open' && clampedIndex === 0;`
  Adjust `prevDisabled` so prev is enabled when `canClose`.
- `closeCover = () => prefersReducedMotion() ? setCoverState('closed') : setCoverState('closing');`
- `handlePrev = () => { if (canClose) return closeCover(); flipControlsRef.current?.prev(); };`
  (prev button `onClick`).
- **ArrowLeft**: window keydown effect gated on `canClose` → `closeCover()`.
  PageFlip's own ArrowLeft also fires but no-ops at index 0 — no conflict.
- **Swipe-right** (the one careful bit, since PageFlip owns swipe and can't be
  touched): attach `onPointerDown` / `onPointerUp` to the **book wrapper**
  (ancestor of PageFlip's container — pointer-capture events still bubble up to
  it). On pointerup, **only** when `canClose` and the delta is a rightward swipe
  past `SWIPE_THRESHOLD_*`, call `closeCover()`. When `!canClose`, do nothing →
  PageFlip handles the gesture normally (no regression). Leftward / next swipes
  are ignored by this handler in all cases.

### BookCover — `'closing'` render
Render `BookCover` whenever `coverState !== 'open'` (now includes `'closing'`).
Closing render = same layers as `'opening'`, reversed:

- leaf `.page-flip-sheet--prev` (`-180° → 0°`)
- card `.book-cover-card--closing` with `@keyframes book-cover-collapse` (reverse
  of `book-cover-expand`)
- `onAnimationEnd` → `setCoverState('closed')`.

## Manual verification
1. **Open at spread 0**: prev enabled; prev button / ArrowLeft / swipe-right each
   play the reverse animation back to the centered closed cover; spine fixed.
2. **At spread > 0**: prev / ArrowLeft / swipe behave as normal page-turns
   (PageFlip regression check); swipe-left (next) anywhere unaffected.
3. **Reduced motion**: close is instant.
4. **No-cover booklet**: prev at index 0 stays disabled, no close path; normal
   flips unchanged.
5. Quiz still renders on the last spread. `npm run lint` + typecheck clean.
