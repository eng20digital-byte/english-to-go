# C4.3 — Sequential re-close animation (flip → collapse)

> Last of the [C4](./C4-cover-open-rework.md) fix set. Mirror of
> [C4.2](./C4.2-sequential-open-animation.md) for the re-close-from-spread-0 path
> ([C3.4](./C3.4-reclose-from-spread-0.md)).

## Goal

Make re-close the exact reverse of the new sequential open:

1. **Flip shut** — the cover leaf rotates `-180° → 0°` (normal `page-turn-prev`),
   folding back over the right page.
2. **Collapse (slide back)** — the open spread collapses back to the centered
   half-page cover (`book-cover-collapse`: re-clip to the right half +
   `translateX → -25%`).

On the **card's** `animationend` → `onCloseEnd` → `'closed'`. Reduced motion stays
instant.

## How

Same trick as C4.2, reversed: the leaf flip runs first (delay `0`), the card
collapse is delayed by the flip duration (`PAGE_FLIP_DURATION_MS`). Because the
card now finishes **last** on close, the close callback must move from the leaf to
the **card** (open keeps it on the leaf — see C4.2).

## Exact changes

### index.css

`book-cover-collapse` keyframes unchanged (still the reverse reframe). Timing only:

- `.book-cover-card--closing` runs `book-cover-collapse` for the reframe duration
  (`var(--reframe-dur)`) with **`animation-delay: var(--flip-dur)`**
  (= `PAGE_FLIP_DURATION_MS`) so the collapse waits for the leaf to finish folding
  shut. Before the delay elapses the card holds the open framing (no clip,
  `translateX(0)` — its non-animated state), so the flip plays across the full
  spread.
- The leaf (`.page-flip-sheet--prev`) + shades run `page-turn-prev` /
  `page-flip-shade` for `PAGE_FLIP_DURATION_MS`, delay `0`.

### BookCover — closing branch

- Card inline style (closing): `'--reframe-dur': '${COVER_REFRAME_DURATION_MS}ms'`,
  `'--flip-dur': '${PAGE_FLIP_DURATION_MS}ms'`, `'--easing': PAGE_FLIP_EASING`.
- Leaf + shades (closing): `animationDuration: '${PAGE_FLIP_DURATION_MS}ms'`,
  `animationTimingFunction: PAGE_FLIP_EASING`, **`animationDelay: '0ms'`**.
- **Re-wire the close callback** — close now ends on the card, not the leaf:
  - **Leaf `onAnimationEnd`**: only fires open →
    `if (isOpening && event.animationName === 'page-turn-next') onOpenEnd();`
  - **Card `onAnimationEnd`**: fires close →
    `if (isClosing && event.animationName === 'book-cover-collapse') onCloseEnd();`
  - Keep filtering by `animationName` so a shade's bubbling `animationend`
    (`page-flip-shade`) never triggers either callback early. Total close time
    ≈ `PAGE_FLIP_DURATION_MS + COVER_REFRAME_DURATION_MS`.

## Manual verification

1. **Close is two-phase** — open to spread 0, then re-close (prev button /
   ArrowLeft / swipe-right): the cover **flips shut first**, and **only then** the
   spread collapses back to the centered half-page cover. Exact reverse of the open.
2. **Lands cleanly** — settles on the correctly-sized centered closed cover (C4.1),
   thick-book chrome back; spine fixed; no double-fire / early settle.
3. **At spread > 0** — prev / ArrowLeft / swipe behave as normal page-turns
   (PageFlip regression check); next/swipe-left anywhere unaffected.
4. **Reduced motion** — close is instant.
5. **No-cover booklet** — prev at index 0 stays disabled; normal flips and the quiz
   on the last spread unchanged. `npm run lint` + `npm run build` clean.
