# C3.1 — Reader: split cover from spreads (correctness baseline)

> First of the four-part split of [C3](./C3-reader-closed-cover.md). Assumes
> **C1** (`is_cover`, `add_cover_page`, `pageCanvasSize`, per-page canvas props)
> and **C2** are merged.

## Goal
[ReaderBookletPage.tsx](../../src/reader/ReaderBookletPage.tsx) separates the
cover from the spreads and drives **all** existing open-book logic on the
spreads. No closed stage yet — a cover booklet simply opens straight to spread 0
with the cover excluded. No-cover booklets stay **byte-identical** to today.

This also fixes the latent bug where the portrait cover would currently render as
a full 1920×1080 spread.

## Shared principles (apply across C3.1–C3.4)
- [PageFlip.tsx](../../src/reader/PageFlip.tsx) is **never touched** — the cover
  leaf reuses the existing `.page-flip-sheet` / `.page-flip-face` /
  `.page-flip-shade` CSS unchanged; new CSS only adds `.book-cover-*` rules.
- **Layered safety**: C3.2 ships the full flow with **instant** open/close (which
  doubles as the reduced-motion path). C3.3 / C3.4 only add the animation on top,
  keeping the instant path as the `prefers-reduced-motion` branch.
- **Seamless handoff**: cover width = exactly half a spread (960 vs 1920), so the
  closed portrait card and the "open book" card occupy the same on-screen box by
  construction — called out as a verification point at each boundary.

## Files
- Modify [ReaderBookletPage.tsx](../../src/reader/ReaderBookletPage.tsx) **only**.

## Exact changes
After the loading / error / empty guards, derive:

```ts
const cover = booklet.pages.find((p) => p.is_cover) ?? null;
const spreads = cover ? booklet.pages.slice(1) : booklet.pages; // cover pinned to index 0 (C1)
```

Then replace every `booklet.pages` in the open-book logic with `spreads`:

- `clampedIndex = Math.min(pageIndex, spreads.length - 1)`
- `pageProgress`, `prevDisabled`, `nextDisabled`, `leftSheets`, `rightSheets`
  → `spreads.length`
- `VocabularyPanel page={spreads[clampedIndex]}`
- `<PageFlip pageCount={spreads.length} … renderPage={(i) => … spreads[i] …}>`
- indicator dots / counter → `spreads.length`, `clampedIndex + 1 / spreads.length`

Add a guard: if `spreads.length === 0` (cover-only booklet) reuse the existing
"no pages" empty state for now (proper closed-only handling is left to C3.2).
