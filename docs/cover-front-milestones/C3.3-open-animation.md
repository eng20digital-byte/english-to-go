# C3.3 — Reader: open animation (centered → expanded)

> Third of the four-part split of [C3](./C3-reader-closed-cover.md). Builds on
> [C3.2](./C3.2-closed-cover-instant-open.md) — pure polish on top of the
> already-working instant open.

## Goal
When motion is allowed, replace the instant open with the synchronized
transition: the cover leaf rotates `0° → -180°` around its left (spine) edge;
spread 0 is revealed underneath; the flat card expands single-page → full-spread
and re-centers via an animated `inset()` clip-path + `translateX`. On
`animationend` → `'open'`. Reduced motion keeps C3.2's instant jump.

## Files
- Modify `src/reader/BookCover.tsx` (add `'opening'` layers)
- Modify [index.css](../../src/index.css) — `.book-cover-card--opening` +
  `@keyframes book-cover-expand`; reuse `.page-flip-sheet--next` /
  `.page-flip-face` / `.page-flip-shade`.
- Modify [ReaderBookletPage.tsx](../../src/reader/ReaderBookletPage.tsx)
- **New** `src/reader/prefersReducedMotion.ts` (small shared helper — PageFlip's
  copy stays private / untouched).

## Exact changes

### ReaderBookletPage
- `openCover`: `if (prefersReducedMotion()) setCoverState('open'); else setCoverState('opening');`
- Render `BookCover` while `coverState` is `'closed'` or `'opening'`; pass
  `firstSpread={spreads[0]}` and `onOpenEnd={() => setCoverState('open')}`.

### BookCover — `'opening'` layout
The card is now **full-spread internally** (`aspectRatio 1920/1080`), clipped +
translated to look like the centered portrait page at `t=0`:

- **Base**: `<PageCanvas page={firstSpread} … />` full spread (revealed
  underneath).
- **Leaf**: reuse `.page-flip-sheet.page-flip-sheet--next`
  (`left:50%; width:50%; transform-origin:left center`, `preserve-3d`,
  `0° → -180°`).
  - Front face = the cover (`PageCanvas` cover dims — the leaf is exactly
    cover-sized, so no 200% re-expand trick needed).
  - Back face (`.page-flip-face--back`) = spread 0's **left** page (200% wrapper
    anchored `left:0`, `clip-path: inset(0 50% 0 0)` — same as PageFlip's back
    face).
  - `onAnimationEnd={onOpenEnd}`.

### Card expansion (flat card only)
**HARD RULE**: never `clip-path` / `translate` / `opacity` / `filter` the leaf —
those live on the flat card only.

```css
.book-cover-card--opening { animation: book-cover-expand var(--dur) var(--easing) forwards; }
@keyframes book-cover-expand {
  from { clip-path: inset(0 0 0 50%); transform: translateX(-25%); } /* right half, centered */
  to   { clip-path: inset(0 0 0 0);   transform: translateX(0); }
}
```

Pass `--dur` / `--easing` from `PAGE_FLIP_DURATION_MS` / `PAGE_FLIP_EASING`
([config/reader.ts](../../src/config/reader.ts)). (Exact `translateX%` tuned so
the spine stays visually fixed.)

## Manual verification
1. **Motion on**: open plays the leaf flip + card expansion together; spine
   visually fixed; spread 0 grows in on the left; **no jump** at the start
   (portrait → clipped-spread handoff) and **no seam** at the end (BookCover →
   PageFlip at spread 0).
2. Back face shows spread 0's left page past 90°.
3. **Reduced motion**: still instant.
4. Normal spread flips and no-cover booklets unchanged. `npm run lint` +
   typecheck clean.
